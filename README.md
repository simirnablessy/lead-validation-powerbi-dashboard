# Lead Validation Dashboard – Power BI

## Problem Statement
Analyse a company lead database to check data quality (valid vs invalid records), understand lead coverage by category and state, and track agent-wise workload.

## Tools Used
- Power BI (cards, charts, slicers, tables)
- Excel (data preparation)

## Dashboard
![Dashboard](dashboard.png)

## What the Dashboard Shows
- KPI cards: 724 companies, 667 emails, 704 websites, 5 agents
- Validation split: 610 valid records (84.25%) and 114 invalid (15.75%)
- Companies handled by each agent
- Number of branches by category
- Company headquarters by state
- Email, mobile and website availability by category

## Key Insights
- About 84% of the leads were valid, so roughly 1 in 6 records needed correction.
- Jewellery Store has the most branches (219), while Insurance has the fewest (50).
- Tamil Nadu has the highest number of company headquarters.
- Work was spread across 5 agents, with the highest share handled by one agent (27%).
